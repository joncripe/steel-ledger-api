## Branch naming
`type/short-description`, e.g. `feat/fitmatch-endpoint`, `fix/overlap-check-edge-case`.

Types: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`.

## Commits
`TSL-123 short summary`, e.g. `TSL-19 add FitMatch scoring for kit-level matches`.

## Pull requests
- Fill out the PR template
- `main` is protected, CI must pass before merge
- New architecturally-significant decision? Add an ADR to `/docs/adr`, don't just describe it in a PR

## Review
Solo for now, self-review before merge, required by branch protection.
